# MCP 도구 응답 품질 평가 기준

## 1. 성능 기준

| 도구 유형 | 응답 시간 | 응답 크기 |
|-----------|----------|----------|
| search_* (목록 조회) | < 3초 | 500 ~ 5,000자 |
| get_* (상세 조회) | < 5초 | 500 ~ 10,000자 |
| 캐시 도구 | < 1초 (캐시 히트) | 동일 |

## 2. 정보 완결성

### 검색 결과 (search_*)
- [ ] 총 결과 건수 표시
- [ ] 각 항목에 고유 식별자 포함 (ID, MST 등)
- [ ] 상세 조회를 위한 후속 호출 안내 (도구명 + 파라미터)
- [ ] 결과가 많을 때 검색어 구체화 안내

### 상세 결과 (get_*)
- [ ] 핵심 메타정보 포함 (법령명, 시행일, 소관부처 등)
- [ ] 본문 또는 요약 포함
- [ ] 관련 도구 안내 (판례 검색, 비교 조회 등)

## 3. 에러 처리 품질

- [ ] 빈 검색어 입력 시 사용 예시 안내
- [ ] 잘못된 ID/MST 입력 시 올바른 조회 방법 안내
- [ ] 빈 결과 시 대안 검색어 또는 관련 도구 제안
- [ ] API 오류 시 구체적 원인 및 재시도 안내

## 4. 토큰 효율성

- [ ] 불필요한 이모지/장식 없음
- [ ] 중복 정보 없음
- [ ] 핵심 데이터 위주 포맷
- [ ] 대량 결과 시 요약 + 상세 분리

## 5. 멀티도구 연계성

- [ ] 검색 결과에서 상세 조회용 파라미터 추출 가능
- [ ] 도구 간 데이터 흐름이 자연스러움
- [ ] 관련 도구 안내가 정확함

|------|------|

| B | 1~2개 미충족 |
| C | 3~4개 미충족 |
